# 😂 Joke Generator

A simple and fun web app that generates random jokes with a single click.
Built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Generates random jokes instantly
* Clean and responsive design
* Lightweight and fast
* Beginner-friendly project

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Joke API (for fetching jokes)

## 📸 Preview
